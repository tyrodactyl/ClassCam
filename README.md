# ClassCam

In-browser classroom app for a smart TV with a built-in webcam: random student picker, noise meter that drives screen effects, scenes, characters, phone count, and meme reactions. Everything runs in the browser; no video or audio leaves the device.

- `index.html`: the TV app
- `remote.html`: iPad control page (pair with the code shown in TV Settings → Pair an iPad). Messages are end-to-end encrypted over a public relay.
